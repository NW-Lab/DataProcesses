# ESP-WebSDR オフライン版

> **このフォルダーは、ESPARGOS の ESP-WebSDR をローカル・オフラインで動かすための自己完結パッケージです。** 閲覧アプリ、ブラウザ用フラッシャー、対応ファームウェアのバイナリーを同梱しています。

## 最初に行うこと

ブラウザでファイルを直接開かず、必ず `localhost` のローカルサーバー経由で開いてください。ESP-WebSDR は USB シリアル機能（Web Serial）を使うため、`file:///.../index.html` では接続できません。

| OS | 起動方法 |
|---|---|
| Windows | `start-windows.bat` をダブルクリック、またはコマンドプロンプトから実行 |
| macOS / Linux | ターミナルでこのフォルダーに移動し、`chmod +x start-linux-macos.sh` の後に `./start-linux-macos.sh` を実行 |

起動後、デスクトップ版 Chrome / Edge / Brave で **<http://localhost:8765/>** を開いてください。別のポートを使う場合は `--port 9000` のように指定し、表示された URL を開きます。

停止するには、起動したターミナルで `Ctrl+C` を押します。

## オフラインで使える範囲

- `index.html` — ESP32 系ボードのスペクトラム／ウォーターフォール表示
- `flash.html` — ブラウザ上のファームウェア書き込み画面
- `firmware/` — フラッシャーが読む全対応プロファイルのファームウェア、マニフェスト、チェックサム
- `flasher/vendor/` — ブラウザ用書き込み機能の同梱依存関係とライセンス

起動時およびファームウェア書き込み時のファイル取得はこのフォルダー内だけで完結します。画面内の **ESPARGOS / GitHub / Z2Labs** のリンクは、クリックしたときだけ外部サイトを開きます。ネットワークを完全に遮断しても、Web Serial による表示・ローカルのファームウェア書き込みは利用できます。

## ブラウザと接続の要件

- **推奨ブラウザ:** デスクトップ版 Chrome、Edge、Brave（Web Serial 対応）
- **起動に必要なもの:** Python 3（ローカル HTTP サーバー用。追加の Python パッケージは不要）
- **受信機:** ESP-SDR ファームウェアを書き込んだ対応 ESP32 ボードと USB ケーブル
- 他のシリアル監視ツールや IDE が同じ USB シリアルポートを開いている場合は閉じてください。

`http://localhost` はブラウザで安全なローカルコンテキストとして扱われるため、Web Serial を使用できます。この同梱サーバーは `127.0.0.1` のみに待ち受け、LAN には公開しません。

## ファームウェアを書き込む場合

1. ローカルサーバーを起動して **<http://localhost:8765/flash.html>** を開きます。
2. 実際のチップとフラッシュ容量に合うプロファイルを選びます。
3. **Connect device** を選び、USB デバイスを選択します。
4. **Install ESP-SDR firmware** を選びます。

> **注意:** 書き込みはボード上の既存ファームウェアとパーティションテーブルを置き換えます。チップ種別を必ず確認してください。ボードがブートローダーへ入らない場合は、上流プロジェクトの案内どおり BOOT を押したまま RESET／再接続を行ってください。

同梱フラッシャーはマニフェストに記載された SHA-256 と書き込み後の MD5 を確認します。ESPtool を使って書き込む運用を希望する場合は、同梱の各 `firmware/<profile>/flash_command.txt` と `flash_args` がオフライン参照用の書き込み情報です。実行する esptool コマンドは、使用するポートとチップに合わせてご自身で確認してください。

## ESP-WebSDR を使う場合

1. **<http://localhost:8765/>** を開きます。
2. **Connect ESP-SDR** を押して、対象ボードの USB シリアルポートを選びます。
3. 中心周波数・ゲイン・サンプルレートを設定します。
4. スペクトラムとウォーターフォールを確認します。

### Wi-Fi CH 表示

スペクトラム下部の測定バーに **Wi-Fi CH** を表示します。中心周波数が標準の Wi-Fi チャンネル中心周波数と一致する場合は、そのチャンネル番号と帯域を表示します。中心周波数が一致しない場合は、受信スパン内にある標準チャンネルを要約表示します。

- 2.4 GHz: CH 1–14
- 5 GHz: CH 36–177 の主要な 20 MHz チャンネル
- 6 GHz: CH 1–233 の 20 MHz チャンネル

この表示は周波数の対応表であり、接続したボードの対応可否、地域ごとの利用可否、または電波法上の利用可否を保証するものではありません。

受信可能な周波数、帯域、サンプルレートはチップと書き込んだファームウェアにより異なります。法令・電波利用規則・受信機器の条件を守ってください。

## 更新・完全性確認

このパッケージは更新を自動取得しません。新しい版が必要なときだけ、ネット接続可能な環境で上流の ESPARGOS リポジトリーから新しいスナップショットを取得してください。

`SHA256SUMS.txt` は、この配布フォルダー内のファイル完全性確認用です。Linux/macOS では以下で検証できます。

```sh
sha256sum -c SHA256SUMS.txt
```

Windows では PowerShell の `Get-FileHash` などで照合できます。
